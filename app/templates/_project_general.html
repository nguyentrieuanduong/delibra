Document conversion

{{ takes_effect("new_session") }} {% if not coding_local %}

Only this machine can change document conversion.

{% endif %}
{% set dl_convert = typed.get('downloads_convert') if 'downloads_convert' in typed else coding.downloads.convert %}

What: PDF, Word (.doc, .docx), Excel (.xls, .xlsx) and PowerPoint (.pptx) files. The type is read from the content (Magika), never from the file name. Text files and other content are not converted: a download's conversion is marked skipped, a requested file's is refused, each with the reason.

When: automatically after each downloaded document, while Downloads above are on; and when an agent asks for a project file in a chat reply, an Auto discussion turn or an Auto build turn.

Where: a download's Markdown copy goes beside it (<file>.md); a requested file's goes to {{ coding.downloads.folder }}/converted/ under its project path, and a requested file that has not changed is not converted again.

How: one at a time for the whole server (the others wait in the queue shown in the chat's Conversions panel, where this machine can cancel them), in a sandbox with no network. PDFs use the models from Settings → Converter; without them a PDF becomes plain text with pypdf. Word, Excel and PowerPoint files need no models.
