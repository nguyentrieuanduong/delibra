Build guidance presets

Each preset becomes a Use <name> guidance button in a project's Coding settings that sets the project's two lists. Pasted every turn: files added to every build turn (at most 32 files and 256 KB). Agents can read: files copied read-only into each build run, listed with each skill's name and description, for agents to open when they need them (at most 512 files and 4 MB); for a skill suite, paste its router skill and put the rest here. Choose… browses this machine's folders: tick .md files or folders and add them; a folder adds the .md files it holds at that moment. A preset keeps fixed lists and the Coding button copies them, so pick again after a skill gains files. Up to 32 presets.

Approval steps in guidance (for example brainstorming's design approval or writing-plans' plan approval) do not stop a build run: the other agents approve instead, and you are asked only if they have not agreed within 3 cycles.

Leave out finishing-work and using-git-worktrees: they merge, push or work outside the project, and Delibra makes the build commits itself.
